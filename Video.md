## Project Summary

The project implements a digital greenhouse frost-protection window controller using Verilog RTL and targets the SkyWater SKY130 standard-cell library (`sky130_fd_sc_hd`). The controller uses temperature thresholds and hysteresis to control window opening and closing, supports manual override, and asserts a frost alarm at low temperatures. The project workflow includes RTL simulation, synthesis, timing analysis, gate-level simulation, and physical design.
